# IPL Cricket Player Analysis using Machine Learning

## Project Overview
This project analyzes IPL player statistics using Machine Learning. The players are grouped into different clusters based on their batting and bowling performance using the K-Means Clustering algorithm.

## Dataset
- IPL_Data.csv

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Features
- Data Preprocessing
- Feature Selection
- K-Means Clustering
- Player Segmentation
- Data Visualization

## Files
- IPL_Cricket_Analysis.ipynb
- IPL_Data.csv
- IPL_Player_Clusters.csv
- README.md

## Output
The project groups IPL players into different performance-based clusters and saves the clustered dataset as `IPL_Player_Clusters.csv`.
